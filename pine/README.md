# 高値圏/安値圏ライン 10案（TradingView・別ウィンドウ用）

10本とも**別ウィンドウ**（価格チャートの下）に表示され、見た目はそろえてあります。

- なだらかなメインライン1本（−100〜+100、0が中立）
- 赤の**高値圏ライン**と緑の**安値圏ライン**

読み方:

- メインラインが赤い線を**上抜け → 高値圏突入**、緑の線を**下抜け → 安値圏突入**。
- ラインに近づくほど線の色がグレーからオレンジ（上）／薄緑（下）に変わる。これが「そろそろ」の合図。
- ゾーンから戻ったら**離脱**（ラインの上に小さな▼▲）。天井（底）を過ぎた可能性のサイン。
- ラベルとアラートは**足が確定した時だけ**出るので、あとから消えたり動いたりしません。確定前は右上の状態表に「（確定前）」と出ます。

10本はそれぞれ**違う要素**から作っています（似た材料の作り直しはなし）。

| ファイル | 名前 | 要素 | 種類 | ライン |
|---|---|---|---|---|
| E01_regression_kairi.pine | 回帰トレンド乖離 | 乖離（平均からの行き過ぎ） | 先行（行き過ぎの終盤） | ±60 |
| E02_tsi_balance.pine | 勢いバランス（短期TSI） | 勢い（上げ幅と下げ幅の綱引き） | 先行（極値の約2本前） | 自動調整（35〜75） |
| E03_speed_retention.pine | 失速率 | 加速・失速 | 確認寄り（極値の0〜1本後） | ±45 |
| E04_volume_cog.pine | 出来高重心 | 出来高 | 状況（2〜5本前から警戒） | ±60 |
| E05_swing_age_maturity.pine | 日柄成熟度（大波） | 日柄（時間） | 先行（最後の新値の足） | ±70 |
| E06_swing_extension_pct.pine | 値幅達成率 | 値幅 | 先行（新値の足） | +70 / −55 |
| E07_cycle_phase.pine | サイクル位相 | 周期 | 先行（山の2〜3本前） | ±85 |
| E08_hhhl_streak.pine | 高値・安値切り上げ連続 | 連続（疲れ） | 先行（極値の足） | ±65 |
| E09_reversal_impulse.pine | 反転インパルス | ローソク足の形 | **確認型**（極値の翌足） | ±45 |
| E10_vol_term_gauge.pine | 恐怖・慢心ゲージ | 値動きの荒さ | 底は当日／高値圏は「慢心」の警戒 | ±60 |

## 使い方
1. PC かウェブ版の TradingView で「Pine エディタ」を開き、`.pine` ファイルの中身を全部貼り付けて「チャートに追加」を押す。
2. 保存すると、iPhone アプリの「インジケーター → マイスクリプト」からも使えます。
3. スマホの縦画面で見やすいのは2〜3枚までです。気になる案だけを表示してください。
4. アラートは「高値圏突入」などを選びます。頻度は「バーの終値で1回」を選んでください。

## 注意
- 初期値は TQQQ などの3倍レバ ETF の**日足**向けです。検証は実際の TQQQ ではなく、NASDAQ総合・S&P500 の実データを3倍に合成したもので行いました。結果は `research/turn_zones/results/summary.md` にあります。
- 1本で捉えられるのは15%以上の天井・底のうち2〜6割ほどです。10本のどれか1つ以上なら約9割を捉えていました。
- この環境からは TradingView に接続できないため、**実際のコンパイルはまだ確認していません**。エラーが出たら、メッセージをそのまま教えてください。
- E05・E06 は過去のスイングを覚えておく分だけ計算が重めです。読み込みが遅い場合は、表示する期間を短くしてください。
- ファイルは `research/turn_zones/build_pine.py` が共通部品から生成しています。直すときは生成元を直して再生成してください:
  ```bash
  python -m research.turn_zones.build_pine
  ```
