## データ準備

### 必須データ形式

実績データは以下の形式で準備してください：

#### CSVファイルの例

```csv
Date,合計,件数(～12:00),件数(～14:00),件数(～15:00),件数(～最終)
2024-01-04,1250,580,850,1100,1250
2024-01-05,1180,550,820,1050,1180
2024-01-09,1320,620,910,1200,1320
...
```

### データ要件

1. **日付列 (Date)**
   - 形式: YYYY-MM-DD
   - 必須

2. **合計列**
   - 1日の受注合計件数
   - 必須

3. **時刻別件数（オプション）**
   - `件数(～12:00)`: 12時までの累積件数
   - `件数(～14:00)`: 14時までの累積件数
   - `件数(～15:00)`: 15時までの累積件数
   - 12時実績による動的補正機能を使う場合は推奨

### データ品質のヒント

- **最低データ量**: 6ヶ月分以上推奨（1年分以上が理想）
- **欠損値**: 休業日は行ごと削除してOK（システムが自動検出）
- **異常値**: 極端な異常値は事前に除外を推奨
- **連続性**: 営業日のデータは漏れなく記録

- **類似日ベース**: 過去の同じ曜日・月初/月末パターンから予測

- 過去の予測誤差を学習して自動補正

#### 3. 信頼度スコア

```
【v66.0信頼度スコア】85.3点 / 100点

推奨: ✅ 信頼できる予測。計画に使用可能

**信頼度の目安**:
- **90点以上**: 最高（誤差±3%以内）
- **80-89点**: 高（誤差±5%以内）

- **60-69点**: 中（誤差±10%以内）
- **50-59点**: 中低（誤差±15%以内）
- **50点未満**: 低（大きな誤差の可能性）

```

- **最終予測**: v65.0アンサンブル + メタ認知AI + 12時実績統合の結果

## トラブルシューティング

### よくある問題

#### 1. "実績表ファイルが見つかりません"

**原因**: ファイル名が規則に合っていない

**解決方法**:
- ファイル名を `実績表_XXXX.csv` または `実績表_XXXX.xlsx` に変更
- または、コード内の `data_file` 検索部分を修正

#### 2. "Date列が見つかりません"

**原因**: 日付列の名前が異なる

**解決方法**:
- CSV/Excelの日付列を `Date` にリネーム
- または、`prediction_date` 列名も対応しています

#### 3. "VIF計算エラー"

**原因**: v66.0で修正済みですが、稀に発生する可能性

**解決方法**:
- データに極端な異常値がないか確認
- NaNやinf値が含まれていないか確認

#### 4. メモリ不足エラー

**原因**: データ量が多すぎる、またはRAM不足

**解決方法**:
- Google ColabでGPUランタイムを使用
- データを直近2-3年分に絞る

#### 5. 予測精度が低い

**原因**: データ品質、季節性、特殊イベント

**改善方法**:
- データ量を増やす（1年以上）
- 特殊イベント（システム移行など）の日付を確認
- 12時実績を入力して動的補正を活用
