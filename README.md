# 個人別 作業達成度と改善分析（物流ダッシュボード）

倉庫作業（ピッキング／梱包）の担当者別 作業実績を集計し、ダッシュボードで
可視化する Excel テンプレートです。

- **ファイル**
  - `個人別作業達成度と改善分析_2026.6.xlsx` … 6月版（下記「③・④の表示改善」を適用）
  - `個人別作業達成度と改善分析_2026.4.xlsx` … 4月版（下記「標準偏差・偏差値シート」を追加）
- **シート構成**
  - `ダッシュボード` … ①総合達成率 ②ピッキング・梱包 内訳比較 ③改善優先度マトリクス ④改善優先順位
  - `入力` … 担当者名・ピッキング実績・梱包実績（黄色セル）を入力
  - `集計用` … グラフ／一覧用の集計（非表示）
  - `使い方` … 操作手順

## 変更内容（片方のみ入力の担当者を ③・④ にも表示）

これまで **ピッキングと梱包の両方**を入力した担当者だけが ③改善優先度マトリクス
と ④改善優先順位 に表示され、**片方だけ**（例：ピッキングのみ・梱包未入力）の
担当者は集計から外れていました。片方だけの入力でも ③・④ に表示されるように
しました。

- **④ 改善優先順位**
  - 入力済みの片側（例：ピッキング）の「目標との差」でランク付けし、通常の
    優先順位の中に混ぜて表示します。
  - コメント欄に未入力側を明記します（例：「ピッキング改善（梱包未入力）」）。
  - 両方入力済みの担当者どうしの並び順は従来どおりです。
- **③ 改善優先度マトリクス**
  - 入力済みの軸（例：ピッキング）で配置し、未入力の軸は目標線上（中立）に
    置いて名前を表示します。
- **①・② は変更なし**（①総合達成率は両方の入力が必要なため従来どおり、
  ②内訳比較は元々 片方入力でも表示されます）。

### 仕組み（数式）

- `入力!L`（優先キー）: 両方入力時は従来どおり合計差、片方のみの場合は入力済み側の
  目標差でキーを算出（未入力は従来どおり除外）。
- `集計用!L/M/O`（④表示用）: 片方のみの担当者は入力済みの値・差・注記を表示。
- `集計用!V/W`（③マトリクス座標を新設）: 未入力軸は目標値で中立配置。散布図
  `chart3` の各系列を `V`/`W` 参照に変更。
- ブックを開いた際に自動で再計算されるよう `fullCalcOnLoad` を有効化。

## 標準偏差・偏差値シート（4月版 `_2026.4.xlsx`）

ピッキング／梱包／合計実績の**標準偏差**と、担当者ごとの**偏差値（優秀度）**を
表示する `偏差値` シートを追加しました（ダッシュボードやグラフは変更なし）。

- **サマリー**: 各工程の 人数(N)・平均・標準偏差（母集団 `STDEVP`）。
- **偏差値表**: 担当者ごとに ピック／梱包／合計 の偏差値、総合偏差値、判定を表示。
  - 偏差値 = `50 + 10 ×（平均 − 実績）÷ 標準偏差`。**実績（分/個）が小さい＝速い
    ほど高い**（偏差値50＝平均、60以上＝優秀）。
  - 総合偏差値 = ピック偏差値・梱包偏差値の平均（片方のみ入力の担当者は入力側のみ）。
  - `順位` 列（`RANK`）で優秀な順が一目で分かります。判定は 優秀／やや優秀／標準／
    やや要改善／要改善 の5段階。
- 母集団標準偏差を採用（偏差値の定義に合わせるため）。標本標準偏差にする場合は
  `STDEVP` を `STDEV` に変更。
