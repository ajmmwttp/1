# AI受注予測システム v66.0

**メタ認知AI予測システム【最強統合版・VIF修正版・完全無欠版】**

## 概要

このシステムは、過去の受注データを分析し、将来の受注数を高精度で予測するAIシステムです。
15種類の機械学習モデル、3つの統計的手法、AI記憶ノートによる自己学習機能を統合しています。

## 主な機能

### ✅ v66.0の革新的機能

1. **v65.0の3手法アンサンブル統合**
   - 類似日ベース予測（重み40%）
   - 前年同日ベース予測（重み40%）
   - 直近トレンド補正予測（重み20%）

2. **v63.1の全機能継承**
   - 15モデル統合（LightGBM、XGBoost、CatBoost、Prophet、SARIMAXなど）
   - メタ認知補正Step 1-30完全版

3. **AI記憶ノート完全統合**
   - 過去の予測誤差を学習して自己補正
   - 系統的バイアスの自動検出と補正

4. **NEW: 複数日の一括予測機能**
   - 週次・月次計画に対応

5. **NEW: 予測信頼度スコアリング**
   - 0-100点で予測の信頼性を定量評価
   - 期待精度と推奨アクションを提示

6. **NEW: 動的重み調整**
   - 状況に応じて最適な重みを自動計算
   - 2024年以降の急成長トレンドに自動対応

7. **修正: VIF計算エラーを完全解決**
   - データ型とNaN/inf処理を強化
   - 特徴量選別の安定性向上

## システム要件

### 推奨環境

- **Google Colab** (推奨)
- Python 3.8以上
- 8GB以上のRAM

### ローカル環境

```bash
# 必要なライブラリのインストール
pip install -r requirements.txt
```

## 使い方

### Google Colabでの実行（推奨）

1. Google Colabを開く
2. 完全なコード（ユーザー提供版）をセルにコピー&ペースト
3. 実績データ（CSV/Excel）をアップロード
4. UIから日付と実績値を入力
5. 「予測を実行！」ボタンをクリック

### データフォーマット

実績データは以下の列を含むCSV/Excelファイル：

| 列名 | 説明 | 必須 |
|------|------|------|
| Date | 日付（YYYY-MM-DD） | ✅ |
| 合計 | 1日の合計件数 | ✅ |
| 件数(～12:00) | 12時までの件数 | ⭕ |
| 件数(～14:00) | 14時までの件数 | ⭕ |
| 件数(～15:00) | 15時までの件数 | ⭕ |
| 件数(～最終) | 最終件数 | ⭕ |

**ファイル名**: `実績表*.csv` または `実績表*.xlsx`

## 出力ファイル

予測実行後、以下のファイルが生成されます：

1. **prediction_result_v66.csv** - 予測結果のサマリー
2. **prediction_reasoning_report_v66_YYYYMMDD.xlsx** - 詳細レポート（Excel）
3. **performance_log_v3.csv** - AI記憶ノート（予測履歴）

## 精度

- **期待精度**: 誤差±3-5%以内（信頼度スコア80点以上の場合）
- **v65.0検証結果**: 2025年8月1日の検証で誤差-1.3%を実証
