# TurnLine 実データ検証レポート

2026-10-29。サンプル画像（案F）の「そろそろ高値／そろそろ安値」の考え方と表示が本当にそれでよいかを、実データで検証した。

## 結論

1. **別ウィンドウに1日1本の棒を出す表示（段階色・右端の段階帯）は、このままでよい。** 実データのギザギザな値動きでも、棒の表示なら読める。
2. **ただし、中身と札の意味は変える必要がある。** サンプル画像の棒は、天井・底に向かってなだらかに伸び、転換点ちょうどで終わっていた。これは未来の転換点を知っている前提の絵で、リアルタイムでは作れない。
3. **底側（そろそろ安値）には、ある程度の情報がある。** 意味は「売られすぎで、底が近いかもしれない」。
   - 上昇基調の相場（2011〜2018年、1991〜1998年）では、点灯の 74〜88% で10本以内に底が来た。値動きの向きをでたらめにした偽の価格では 50〜57% なので、偶然ではない。
   - 暴落・下落相場（2019〜2022年）では 50% で、偶然と同じだった。
     - コロナ急落の2020年は、点灯5回のうち空振り3回。最初の点灯から本当の底まで、さらに最大 73%（3倍換算）下げた。
     - 2022年は、点灯10回のうち空振り6回だった。
   - 点灯しても、その後さらに中央値で 2〜6%（3倍換算）下げることがある。
4. **天井側（そろそろ高値）は予告できない。**
   - 的中は 21〜31% で、偽の価格（30〜44%）以下だった。
   - 点灯は天井の中央 21〜33 本前と早すぎ、その後もさらに中央値で 10〜15% 上がる。
   - 「そろそろ高値」の札は出さず、「過熱」の参考表示にとどめるべき。
5. **天井・底の「確定」は、リアルタイムでは遅れる。**
   - 遅れの中央値は、2011〜2018年で天井 7〜8 本・底 4 本。
   - サンプル画像は転換点ちょうどに確定札を描いていたが、これは後知恵。確定札は確定した日に置く。
6. **中身は単純な TL-Classic3 で十分。** RSI・ストキャスティクス・移動平均乖離の3つを、重みを学習せずに等重みで合成したもの。機械学習や学習ブレンドも試したが、RSI14 並みで上積みはなかった。

## 何をどう検証したか

| 項目 | 内容 |
|---|---|
| データ | TQQQ 本体は、この環境のネットワーク制限で取得できなかった。代わりに Python パッケージ（arch・skfolio）に同梱の実データを使い、NASDAQ総合と S&P500 の日足の値動きを日次で3倍にした近似を作った（経費率 年0.95%）。期間は 1990〜2022年。2019〜2022年と1991〜1998年は終値だけのデータ（高値・安値なし） |
| 正解（天井・底） | 高値・安値の ZigZag で決めた。反転幅は 1.5×(10日分の変動率) で、通常の TQQQ 相当でおよそ 15%、荒れた相場では大きくなる。天井・底は年 3〜5 回ずつで、ユーザーのチャートの山・谷と同じくらいの大きさ |
| 候補 | 3系統×2 で計6つ。① オシレーター・サイクル系、② 疲れ・時間・ハザード系、③ 機械学習系。比べる基準は RSI14 と理想形（サンプルの作り方＝未来を使う上限） |
| 公平さのルール | 未来の情報は使わない（途中で切ったデータで計算し直して値が変わらないことを自動検査）。学習・調整は 1999〜2010年の NASDAQ だけで行った。2011〜2018年・2019〜2022年・1991〜1998年は、調整に使っていない期間 |
| 反証検証 | 系統ごとに別の担当が独立に再計算し、未来参照・過学習・数字を確かめた。さらに「値動きの向きだけをでたらめにした偽の価格」（鏡映帰無）と、変動率の性質を残した GARCH シミュレーションで、偶然でも出る成績かどうかを検定した |

指標の読み方:
- 的中率: 「そろそろ」が点灯してから10本以内に、同じ側の転換点が来た割合
- 事前点灯率: 天井（底）の前に一度でも点灯した割合
- 何本前: 最初の点灯が転換点の何本前だったか
- 残り値幅: 点灯してから実際の天井（底）までに、まだ動いた幅

## 表示（案F）への影響と修正案（案F'）

1. **底側の棒を主役にする。**
   - 札は「そろそろ安値」より不確かさが伝わる「底が近いかも」にする。
   - 段階名は 安値に注意 → 底が近いかも → 売られすぎ（圏）。
   - 的中の目安（上昇基調の相場で約7〜9割、暴落・下落相場で約5割）を添える。
2. **天井側の棒は「過熱」として控えめな色にする。** 札は出さず、「天井の予告には使えません」と明記する。
3. **確定札は、実際に確定した日に置く。** 転換点（後から分かる位置）から確定までを点線でつなぎ、遅れが見えるようにする。
4. **平滑化はしない。** 札は一度点灯したら 35 未満に下がるまで出し直さない（ヒステリシス）。これで1回の局面に札1枚になる。
5. **棒の表示（案F）が、山と谷の線（案H）より向いている。** 実データは日々ギザギザなので、線でつなぐと読みにくい。

## 候補の比較（調整に使っていない期間）

| 候補 | 2011–18 天井 的中/AUC | 2011–18 底 的中/AUC | 2019–22 天井 的中/AUC | 2019–22 底 的中/AUC |
|---|---|---|---|---|
| RSI14（基準） | 0.33 / 0.66 | 0.85 / 0.83（年1.6回のみ） | 0.25 / 0.72 | 0.67 / 0.83（年1.5回のみ） |
| TL-Classic3（等重み・推奨） | 0.31 / 0.69 | 0.88 / 0.88 | 0.26 / 0.71 | 0.50 / 0.87 |
| TL-Blend（ロジスティック合成） | 0.36 / 0.69 | 0.76 / 0.88 | 0.33 / 0.69 | 0.47 / 0.87 |
| 脚ハザード＋勢い | 0.39 / 0.69 | 0.68 / 0.88 | 0.20 / 0.69 | 0.45 / 0.88 |
| 疲れ指標（TD・連続日数） | 0.34 / 0.69 | 0.71 / 0.87 | 0.25 / 0.68 | 0.46 / 0.86 |
| 機械学習（ロジスティック回帰） | 0.37 / 0.68 | 0.84 / 0.85 | 0.33 / 0.73 | 0.50 / 0.85 |
| 機械学習（勾配ブースティング） | 0.26 / 0.66 | 0.86 / 0.85 | 0.24 / 0.70 | 0.46 / 0.84 |
| 理想形（未来を使う上限） | 0.59 / 0.91 | 0.90 / 0.95 | 0.33 / 0.92 | 0.83 / 0.97 |

- どの候補も、天井側の的中率と AUC は偽の価格を上回れなかった（p=0.15〜1.00）。反証検証と、追加で回した鏡映帰無で確認した。
- 底側は、候補どうしの差が誤差の範囲で、RSI14 を同じ点灯回数に合わせたものともほぼ同じ。
- ただし、偽の価格に対して底側の的中率が有意（p<0.05）だった期間の数には差があった。TL-Classic3 は4期間中3つ、脚ハザードは2つ、TL-Blend は1つ。
- だから、いちばん単純で過学習の余地がなく、しかも最も安定していた TL-Classic3 を推奨する。
- 機械学習の勾配ブースティングは、学習期間と未使用期間の差が大きく（過学習）、勧めない。
- 正解の定義（ZigZag の反転幅の倍率）を 1.0 や 2.0 に変えても、結論は変わらなかった（sensitivity.py）。

## 文献との整合

詳しくは literature_notes.md。
- 多数の売買ルールを試して一番良いものを選ぶと、未使用期間で消えやすい（Sullivan, Timmermann & White 1999 など）。今回も、学習期間で見えた上積みは未使用期間で消えた。
- 指数の「買われすぎ」は下落の予兆になりにくく、「売られすぎ」の方が情報がある、とする検証が多い。天井より底の方が予測しやすい、とする研究もある。今回の結果と一致する。
- 下落局面ほど変動率が跳ねる（変動率の非対称性）。底側の成績の一部は、この性質で説明できる。GARCH シミュレーションとの比較では、底側の優位は期間によって有意でなくなった。
- レバレッジETFは往復の売買コストと目減りが大きい（Cheng & Madhavan 2009）。空振りの多い天井側のサインで売り買いするのは不利。

## 限界と次の一手

- **限界:**
  - TQQQ 本体ではなく、指数を3倍にした近似で検証した。2019〜2022年は終値だけ。
  - 転換点の数が少ない期間（2019〜22年は天井・底とも12個）では、数字のぶれが大きい。
  - 手数料・スリッページ・税は入れていない。今回の検証は表示（予告の当たり外れ）が対象で、売買ルールとしての損益は検証していない。
- **次の一手:**
  1. TQQQ の実データ（2010年〜）が取れる環境で、同じハーネスで再検証する（下の手順で `L.load` を差し替えるだけ）。
  2. 案F' を Python で実装する（TL-Classic3 を使う）。
  3. 下落相場で「底が近いかも」が早すぎる問題の対策を検証する。例: 長期の下落トレンド中は札を弱める、変動率が急上昇中は1段階下げる。
